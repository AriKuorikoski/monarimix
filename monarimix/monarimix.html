Time-sig setup & help

REAPER's OSC bridge has no time-signature alias, so we set it via a tiny ReaScript. One-time setup:

  1. In REAPER: Actions menu → Show action list.
  2. Click New action… → Load ReaScript….
  3. Pick monarimix_set_timesig.lua from your REAPER folder.
  4. Find Script: monarimix_set_timesig.lua in the list and run it once (double-click, or highlight + click Run).

That's it — the page picks up the script's ID automatically on the next poll. The status above the “Time-sig setup” toggle will flip to a green ✓ within a second.
